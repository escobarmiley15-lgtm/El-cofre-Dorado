# El Cofre Dorado
Aventura de Exploración: Busca el Cofre Dorado es un juego en el que un aventurero explora un mundo misterioso, recolecta objetos, resuelve acertijos, evita trampas y derrota enemigos. Su objetivo es encontrar el Cofre Dorado y obtener recompensas y logros.
Estructura del juego

1. Menú principal

Nueva partida

Cargar partida

Opciones

Salir

2. Crear una nueva partida

Elegir el nombre del aventurero.

Seleccionar la dificultad: fácil, normal o difícil.

Iniciar la aventura.

3. Exploración del mapa

Buscar objetos y recursos.

Encontrar pistas.

Interactuar con personajes.

Descubrir la ubicación del templo.

4. Entrada al templo

Resolver acertijos.

Evitar trampas.

Enfrentar enemigos.

Superar los desafíos para avanzar.

5. Encontrar el Cofre Dorado

Llegar a la cámara secreta.

Abrir el cofre.

Obtener monedas, objetos especiales y logros.

6. Recompensas y resultados

Mostrar los objetos obtenidos.

Mostrar las monedas y los logros.

Guardar el progreso del jugador.

7. Final del juego

Preguntar si desea jugar de nuevo.

Si responde sí, comenzar otra partida.

Si responde no, salir del juego.

8. Opciones adicionales

Guardar y cargar el progreso.

Consultar el estado del jugador.

Cambiar configuraciones.
# Fase 1 - Analisis
El juego consiste en explorar un mundo misterioso para encontrar el Cofre Dorado. Durante la aventura, el jugador debe recolectar objetos, buscar pistas, resolver acertijos, evitar trampas y enfrentarse a enemigos. Su objetivo principal es superar los desafíos y llegar al tesoro.

Progreso del juego: El jugador comienza en el menú principal, donde puede iniciar una nueva partida o cargar una partida guardada. Después, avanza por diferentes zonas del mapa, consigue recursos y descubre pistas que le permiten acercarse al templo. Allí debe superar pruebas hasta encontrar el Cofre Dorado y obtener recompensas. El progreso puede guardarse para continuar la aventura después.

Este juego ayuda a desarrollar la lógica, la creatividad, la toma de decisiones y la capacidad para resolver problemas.
